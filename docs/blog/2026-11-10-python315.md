Support for Python 3.15 (including the free-threaded `nogil` build) was added in the latest release. Python 3.12 is no longer supported; the minimum version is now 3.13.

<!-- truncate -->

See [what's new](https://docs.python.org/3.15/whatsnew/3.15.html) in Python 3.15.

Also check out the [latest release](https://github.com/mliezun/caddy-snake/releases) of caddy-snake.
